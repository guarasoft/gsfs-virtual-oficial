# Referência Visual de Apoio

Esta pasta guarda as **imagens de apoio** da linguagem visual do GSFS (não são logos nem tokens — são referências estéticas para as telas).

Conforme o sistema de identidade v1.0 (seção "Visual Language"), os motivos são:

- **Topographic Lines** — terreno, profundidade, precisão.
- **Data Fusion Grids** — dados em camadas, inteligência unificada.
- **Technical HUD Elements** — precisão, varredura, medição.
- **Data Visualization** — dados complexos em insights claros.
- **Depth & Discovery** — revelar o que está sob a superfície.

## A popular (PR-06)

As imagens de referência enviadas pelo cliente (fundos topográficos, grids de fusão, etc.) devem ser salvas aqui, nomeadas por motivo, por exemplo:

```

├── topographic-lines_01.png
├── data-fusion-grids_01.png
├── technical-hud_01.png

```
